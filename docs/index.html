The ad that listens.

A travel ad you can interrupt. A show plays on NotFlix, and at the ad break a live, AI-generated Amalfi Coast appears with a narrator. Hold Space and ask it something. The narration stops, the ad answers out loud in the same voice, and the world on screen moves to show you.

The run

One ad break, start to finish.

These are frames from one real run on a MacBook. The questions were spoken into the voice agent; nothing below is mocked.

  1. 0:00

    A show is playing

    NotFlix is a Netflix-style streaming app. The show is Big Buck Bunny, the Blender Foundation’s open film.

  2. 0:13

    The ad gets ready in the background

    While the show plays, the app opens a world-model session and the voice agent. Start the ad lights up only when the world is already streaming, so the break never shows a loading screen.

  3. 0:14

    The break

    The show eases back, a bumper says the ad listens, and the live world fades in.

  4. 0:24

    The narration

    Sixteen scripted lines, about two minutes. Each line carries a shot direction, so the world moves through a day on the coast: the lobby, breakfast, the coast road, a boat, the pool, the rooftop.

  5. 0:46

    You interrupt

    Holding Space opens the mic and stops the narration at once. Your words appear on screen as you say them.

  6. 0:50

    It answers, and the picture changes

    The agent prices the stay with a tool, says it, puts a card up, and sends the world a new shot. Then the narration picks up at the next line.

  7. 3:03

    Back to the show

    With three questions asked, this break ran just under three minutes. When the script ends and nobody is talking, an end card shows and the show resumes where it stopped.

The script

A day on the coast, in sixteen lines.

Each narration line comes with a shot direction for the world model. With nobody asking anything, the ad walks through a day: breakfast, the coast road, a boat to Capri, the pool at golden hour, dinner on the rooftop.

Ask it

Every answer moves the picture.

The agent picks a shot for each answer and sends it to the world model as a one-line direction. The world takes four to eight seconds to get there, so it changes while the answer is still being spoken.

Reactor

A world you direct while it plays.

HappyOyster, on Reactor, is a world model: it generates video live, frame after frame, and keeps generating for minutes. In its Directing mode you can send it a line of text at any moment and the next few seconds of video follow it.

Once · 2–3 min

Create a world

A prompt of up to 2,000 characters becomes a permanent world on your account. We keep its id and reuse it.

Each break · 6 s

Open a session

The server opens the session with the API key and gives the browser a token bound to that one session.

13 s to first frame

Travel

Reopen the world and start a “travel”: video streams into a normal <video> element over WebRTC.

0.2 s · seen in 4–8 s

Instruct

Send a line of text. The world plans in blocks of about four seconds, so the change lands on the next block or two.

The first world ignored us

Our first prompt described a pretty coast, with the calmest settings. We sent it “night falls, lanterns glow along the harbour”. It accepted the instruction and kept wandering through a sunny garden toward a lemon.

What made it follow

Reactor’s prompt guide says instructions can change place and time of day inside a world, and that they work best when they point at things the world prompt already named. So we rebuilt the world around that.

The world prompt 
Photoreal travel commercial, shot on a gimbal and a drone, 35mm film look. You are a traveller arriving at Hilton Amalfi Coast, a cliffside resort above the pastel town of Positano. Recurring landmarks: the Hilton infinity-pool terrace with white umbrellas over the turquoise bay; Terra, the Hilton rooftop restaurant strung with warm lights; the lemon-grove garden; the harbour of wooden boats and the ferry pier; the winding coast road where a cream vintage convertible drives along the cliff. The world moves through the day: bright morning, golden hour, then a lantern-lit night when the whole town glows over the dark water. Boats come and go, waiters set the rooftop tables, swimmers glide across the infinity pool, the ferry crosses the bay. Warm Mediterranean sunlight, glossy turquoise water, terracotta and lemon-yellow textures, sea spray, fast sweeping drone moves and tracking shots.
An instruction the agent sent 
From 0 to 8 seconds, night falls over the harbour, lanterns glow on the Terra rooftop.

What did not work

Pause and resume do nothing for this world, so the ad never pauses the video: the narration pauses, and the world keeps moving under the conversation. Reactor’s guide also says an instruction cannot take the world somewhere it was not built to contain, so the agent is only offered shots of the coast’s own landmarks.

Limits to plan around

A directing travel lasts about three minutes, which sets the length of the ad and its conversation. A browser cannot open a session with its own token, so the server opens it and hands over a token bound to that session.

How it works

Two programs, three services.

A small Python relay owns all the audio. The streaming app owns all the pictures. They talk over one local WebSocket.

Mac

Mic and speakers

Built-in mic, push to talk. Any mic works; a reSpeaker array is picked up automatically.

Python

Voice relay

Plays the narration, streams your voice while you hold Space, plays the answers, forwards tool calls.

AssemblyAI

Voice Agent

Speech in, answer out, in the narrator’s voice. Calls tools to look things up and to steer the ad.

Next.js

NotFlix

The show, the break, captions, cards. Turns each scene tool call into a world instruction.

Reactor

HappyOyster

A world model that streams live video and follows text directions while it plays.

Why the world never shows a loading screen

Building the world takes over two minutes, so it is built once and its id saved. Each ad break reopens it and starts streaming into a hidden video element while the show is still playing. The break only begins once frames are arriving.

Why every answer changes the picture

The agent is asked to pick a shot for every answer. If a reply starts without one, the relay picks the landmark that best fits the question: a price shows a sea-view room, transport shows the coast road, nearby sights show a boat to Capri.

Run it

On a Mac, nothing to plug in.

You need Node.js 20+, Python 3.11+, an AssemblyAI key and a Reactor key.

  1. Open localhost:3000/notflix and click Play.
  2. Click Prepare ad, then Start the ad when it lights up.
  3. Hold Space, ask, release.
  4. Esc skips the ad. D opens the audio check.
# install
npm install
npm run setup:voice

# keys
cp .env.example .env.local     # REACTOR_API_KEY
echo "ASSEMBLYAI_API_KEY=…" > voice/.env

# two terminals
npm run relay
npm run dev
